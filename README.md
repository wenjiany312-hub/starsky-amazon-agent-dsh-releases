# Starsky · 装在你电脑里的亚马逊运营 AI 团队

> 你说人话，它按岗位分工干活：选品、找厂、写 Listing、出图方案、投广告、备货、巡检、写周报、做表格和 PPT。
> 所有产物落在你指定的本地文件夹，API Key 和店铺数据不出你的电脑。
> 作者：叶文坚（坚哥）｜ 跨境者说干货 · 星空的跨境圈子

## 它替你做什么

| 以前 | 用 Starsky 之后 |
| --- | --- |
| 选品靠感觉，报告靠 PPT 拼，数字说不清来源 | 选品侦察员按「访谈 → 市场穿透 → 1688 找厂 → 供应商评估 → IP 排查 → 可行性报告」一步一停，**关键数字必须带来源，没有数据就不编** |
| 词库、文案、图片、广告各找一拨人，口径对不上 | 一条主链 S1 → S2 → S3 → S4 → Ops：前一岗的产物就是后一岗的输入，词库 / 文案 / 广告用同一套关键词，**YAML + Hash 锁住不漂移** |
| 广告 Bulk 表手工填，填错就上传 | 策略 → 架构 → Bulk 候选 → 校验 → 审阅，用亚马逊官方 Bulksheet 模板生成待审核文件，**绝不替你登录上传** |
| 报表在 Excel 里，AI 在浏览器里，来回复制 | 在会话里直接说「把这份供应商短名单导出成 xlsx」「把市场报告整理成 8 页 PPT」，Excel / Word / PPT 就地生成、预览、导出 |
| 每天打开后台看一圈，靠记忆判断异常 | 运营总监一句话启动店铺巡检：价格、Buy Box、评论、账户健康、库存与广告 ACOS，出巡检报告和待审核动作，按需推到飞书 / 微信 |
| 装环境装半天，Node、Python、依赖一个个踩坑 | 一个安装包，运行时随包，粘贴 DeepSeek Key 就能开工 |

**你拿到的是落盘的交付物，不是聊天记录**：每个项目一个文件夹，`生成报告/` 里是市场穿透报告、产品画像、供应商短名单与评估、IP 排查、可行性报告（Markdown + 精美 HTML）、竞品 ASIN 池、Keyword Package 2.0 词库、中英 Listing、主副图 / A+ / 视频分镜提示词包、广告策略与 Campaign 架构、Bulk 候选文件、巡检周报。换电脑、换 AI，文件都在。

## 一个下午能走完的流程

1. **14:00** 新会话对运营总监说：「美国站，想做 25–55 美金的宠物用品，帮我选品。」它建好项目文件夹、派选品侦察员开工。
2. **14:30** 市场穿透报告出来，附 3–10 个核心词的实测 CPC 与最高可承受 CPC 对照；你选定一个方向。
3. **15:00** 1688 供应商短名单与评估（每一行注明来源工具，编造一条整份作废），IP 侵权排查，综合可行性报告。你拍板选哪个品、哪家厂。
4. **15:30** 「⚡ 接力 → 文案算法师」：竞品 ASIN 池 → 词库 → 中英 Listing 文案，词库口径直接传给后面的美工和广告。
5. **16:30** 创意美工给出主副图 / A+ / 视频分镜的方案与提示词；广告优化师给出新品广告策略、Campaign 架构和 Bulk 候选文件，等你审阅。
6. **17:00** 「把今天的产物整理成一份汇报 PPT。」Univer Office 在会话里直接生成，改到满意再确认落盘。

每一步都是**一步一停**：AI 出证据和方案，人来拍板。系统不会替你登录后台、不会上传、不会付钱、不会发货。

## 随包能力

- **43 个业务技能**：市场穿透、精铺选品方法论、1688 供应商评估与详情抓取、IP 合规排查、产品开发 PRD、上市计划、三条词库线（共享 Keyword Package 2.0 契约）、Listing 文案、类目视觉基准学习、主副图 / 标准与高级 A+ / 视频分镜、广告策略 / Campaign 编译 / Bulk 生成与排错 / 报表分析、店铺巡检总控、领星 ERP 连接器、类目 / 企业适配器、精美 HTML 报告……
- **11 个界面插件**：Starsky 主题、九岗团队面板、经营看板、右侧工作台（文件树 / 预览 / 终端 / Git）、视觉工具（粘图即识、长截图 OCR、像素对比，自带免费在线识图额度）、Univer Office（Excel / Word / PPT / 多维表格 / 白板）、AnySearch 联网搜索（无 Key 可用匿名额度）、计费、IM 网关（飞书 / 微信 / 钉钉）、插件市场、找插件。
- **市场数据接入（选配）**：Sorftime、SIF、卖家精灵、西柚 MCP 填自己的账号 Key 即接入；1688 本地抓取用你自己登录的账号搜厂抓详情；领星 ERP 接 OpenAPI 后巡检与补货走真实库存与广告数据。没有也能跑全流程，只是不会编数字。
- **底座**：DeepSeek 开源的 DeepSeek Harness（MIT）。三层更新——底座跟官方走（三源检测、确认后升级、探测不过自动回滚）、技能角色资产更新、程序自更新，全部手动确认，绝不静默替换。

## 和「直接用 ChatGPT / DeepSeek 聊」有什么不同

- **有分工、有契约**：九个岗位各有职责边界和交接卡，前岗产物是后岗输入，不会聊到第 20 轮口径就跑了。
- **有来源才写数字**：市场数据、CPC、供应商信息必须注明来自哪个工具或哪份导出；没有数据就说没有，不编。
- **产物落盘**：不是一段回复，是可以直接给采购、给美工、给广告代运营的文件。
- **官方模板、不越权**：广告用亚马逊官方 Bulksheet 模板，只生成待审核文件，登录、上传、付款永远是你自己按的。
- **数据在本机**：Key、店铺数据、报告都在你电脑里，AI 只用你自己充值的 DeepSeek 账号。

## 适合谁，不适合谁

**适合**：在做或准备做亚马逊美国站精铺的卖家 / 小团队，想把选品、文案、广告、巡检这套流程跑规范、留档、少犯低级错误的人；愿意自己看报告、自己拍板的人。

**不适合**：想要"一键上架、自动出单"的人——它不替你做决定，也不碰你的后台。

## 需要什么

- Windows 10 / 11（Mac 版随同一仓库构建，在 Mac 上出 dmg）；
- 一个 **DeepSeek API Key**（platform.deepseek.com 自己注册充值，按 token 计费，几十块能跑一整天）；
- 能上网（首次下载官方底座约 100 MB）；
- 一个 **授权码**（见下）。

## 下载与安装

当前版本 **1.5.3**，Windows 与 macOS 同一源码、同一批插件、同一版资产。到 [Releases](../../releases/latest) 取对应平台的包：

| 平台 | 下载 | 安装入口 |
| --- | --- | --- |
| Windows 10 / 11 | `Starsky-Setup-1.5.3.exe` | 双击安装 → 弹「已保护你的电脑」点「更多信息 → 仍要运行」→ 自动打开安装向导 |
| macOS · Apple 芯片（M 系列） | `Starsky-1.5.3-mac-arm64.dmg` | 拖进「应用程序」→ 首次右键 → 打开（或 `xattr -cr /Applications/Starsky.app`）→ 安装向导 |
| macOS · Intel | `Starsky-1.5.3-mac-x64.dmg` | 同上 |

安装向导三步：第一张卡显示**本机指纹**，点「复制申请信息」发到公众号后台（见文末二维码），付费后收到一行 `STARSKY1.` 开头的授权码粘贴进去 → 粘贴 DeepSeek Key → 「底座方式」保持默认，点「开始安装」，等它装完底座、技能、九岗角色、界面插件（首次 3–8 分钟）→ 自动进入工作台 → `Ctrl+N` 打开「今天干什么」挑一张卡片开工。

[安装、授权与更新说明](docs/安装与授权.md) · [更新记录](docs/更新记录.md) · [全部版本](../../releases)

**授权**：一机一码、按年授权；到期后已装内容照常使用，只是不再接收更新，续费换新码即可，不用重装；换电脑按新指纹重新申请。价格与购买方式扫码咨询。

Release 里的 `starsky-assets.zip`、`latest.yml`、`latest-mac.yml`、`*.blockmap` 是程序自动更新用的，不用手动下载；`SHA256SUMS.txt` 是全部文件的校验值。本仓库只放发布物，不放源码；装完的程序更新中心默认指向这里。

**老学员从「星空亚马逊运营Agent系统」升级**：产品自 2026-09-04 起更名 Starsky，appId 变了，Windows 会把它当成新程序：先在旧版菜单「系统 → 彻底退出」，到「设置 → 应用」卸载旧版（不删数据），再装 Starsky。首次打开停在授权页，换码后自动进入工作台，对话、Key、工作区、已装插件全部保留。
